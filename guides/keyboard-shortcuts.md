# Keyboard shortcuts

Press `?` in the web app to see the shortcuts available on the current page. Single-key shortcuts
don't fire while you're typing in a field, the editor, a menu or a dialog.

## Global

| Shortcut | Action |
| --- | --- |
| `Cmd/Ctrl+K` or `/` | Search |
| `?` | Show keyboard shortcuts |
| `N` | Create a Task |
| `C` | Create a Project |
| `H` | Home |
| `W` | My Work |
| `P` | Projects |
| `D` | Documents |
| `I` | Inbox |
| `G` | Discuss |
| `T` | Timesheets, when time tracking is on |
| `1`–`9` | Open a numbered Project shortcut |
| `Cmd/Ctrl+Z` | Undo the last supported change |
| `Cmd/Ctrl+Shift+Z` or `Ctrl+Y` | Redo |

## In a Project

| Shortcut | Action |
| --- | --- |
| `L` | List |
| `G` | Board |
| `B` | Backlog |
| `M` | Milestones |
| `U` | Documents |
| `A` | Actions for the selected Tasks |
| `Backspace` | Clear the selection |

## On the Board

| Shortcut | Action |
| --- | --- |
| Arrow keys | Move focus between cards |
| `Enter` | Open the focused Task |
| `Shift`+arrow keys | Move the focused Task |
| `Shift+Home` / `Shift+End` | Move the Task to the top or bottom of its column |
