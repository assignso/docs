# Logos and spacing

## The mark

The Assign symbol has four rounded open corners and a central dot. Use the [supplied SVG or PNG](/branding#download-the-mark); preserve its proportions, rounded ends and center alignment.

Do not stretch, rotate, crop, outline, redraw or add effects to it. Do not combine other elements with the symbol or replace its dot.

## Clear space

Leave at least one central-dot diameter between the painted mark and surrounding text, artwork or the edge of a layout. On the original 24-unit drawing, that diameter is 7 units. Scale this clearance with the mark.

This is space in the surrounding layout. Keep the supplied canvas unchanged; do not add that clearance inside a favicon or app-icon file.

## Minimum size

Display the mark at no less than **16 CSS pixels** square in a web interface. Use vector artwork where possible. For raster use, choose an export large enough for the display's pixel density and check that the dot and corners remain clear at the final size.

The artwork's size is separate from a clickable control's target area. Provide the surrounding space and interaction behavior that the control needs.

## Favicon and app-icon padding

The mark and favicon use a **24 × 24** canvas. Their painted bounds run from 3.875 to 20.125 units on each axis, leaving the existing inset intact. Scale the whole canvas proportionally.

Web-install artwork uses a separate **32 × 32** canvas with additional inset for its platform purpose. Do not substitute that canvas when matching favicon padding. Let each platform apply its own icon mask; avoid baking rounded corners or system highlights into the original mark.

## Name and logo types

Write the product name as **Assign**. Use the mark alone where space is limited and the product is already clear. Where a name is needed, use ordinary text in the surrounding typography without altering the symbol.

There is no separately supplied custom outlined Assign wordmark. The existing Assign Docs header lockup identifies the documentation; do not repurpose it as a general Assign logo.
